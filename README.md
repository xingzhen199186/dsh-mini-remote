# dsh-mini-remote

> 一个 [DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek-Harness)（DSH）插件，把一部手机变成**极简遥控器**——移动端只收到你发出去的指令和 AI 最后的结论，工具调用、文件读写、子 Agent 调度、思考过程全部留在电脑上。

## 为什么做这个插件

初衷是因为现在AGENT任务执行一轮往往需要很久，而如果出门，则需要手机端来远程操作。

但现有的手机端，会把PC的执行步骤非常还原地展现出来。你发一条指令，它可能要想上几分钟、读几十个文件、调好几次工具，最后才给你一个结论。如果出门或有事不在电脑前，实在没时间盯着手机看那么细致。

我并不认为那种方式不好。信息完整、过程可控，如果你要认真处理任务，它是对的。

但出门在外的时候，就我个人而言，我需要的是另一种东西——**更轻便、更少占用注意力的交互方式**。手机屏幕就那么大，出门时的精力也就那么多。而大部分时候我真正需要的只有一件事：**这一轮跑完了，该发下一条指令了**。而且大部分时间，即使在电脑上，我也很少会去仔细阅读AI做执行过程中的“自言自语”。

所以这个插件的界面做得相当「原始」：它完全省略了电脑网页端的执行步骤，只把 AI 最后的结论送到你面前。

**某种意义上，它的存在，是为了让你更少地去看它。**

你可以更加自由地支配自己的时间，而不是当你和女儿玩耍时，抑或出游时，被困在那个小小的屏幕里。

## 安装

```powershell
dsh plugin --profile web add dsh-mini-remote
```

也可以直接从 GitHub 装，这样锁的是源码：

```powershell
dsh plugin --profile web add github:xingzhen199186/dsh-mini-remote
```

手上有源码目录的话，把目录指给它也一样：

```powershell
dsh plugin --profile web add <你放源码的目录>
```

装完**必须重启一次 DSH**，设置页里才会出现新东西。重启后左栏会多出「手机遥控」，启动日志里也会打印手机访问地址和密码。

**它适配哪些 DSH 版本。** 这个插件在 DSH **0.1.5-rc.2** 上开发，在 **0.1.7-rc.2** 上重新逐项核对过（插件用到的那些接口，一个都没变），**低于 0.1.5 的版本没试过**。`rc` 是官方给预览版编的号，DSH 目前整体还是开发者预览版，跨小版本可能有破坏性改动，所以比 0.1.7 更新的版本同样不保证。真遇上不兼容，症状一般是某一块入口不见了（比如顶栏那行模型），其余部分照常——插件是按「少了哪个服务就关掉哪块功能」写的，不会整个起不来。

## 配置：三条路，按需要选

三条连接方式**同时存在**，选一条就行，也可以都开着。

打开 DSH 设置（侧边栏最下面）→ 左栏「手机遥控」。这一页上每条路都有一个二维码和一条链接，二维码底下那行小字写着**什么时候用这条**，看它就够了。

### 一、内网：只在家里用

手机和电脑连同一个 Wi-Fi 时，扫「内网」那个码就能用。**不需要任何额外安装**，最省事的一条。

代价是出了门就连不上——手机一切到流量，这条就断了。

### 二、Tailscale：出门也能连，地址还固定

电脑和手机都装上 [Tailscale](https://tailscale.com)、登录同一个账号，配对页上就会自动多出这一条。地址固定，配一次以后不用再管。

代价是两边都要装一个 App。如果你不介意装，**出门在外这条最稳**。

这条路上还能再开一步，多拿一个加密地址（形如 `https://你的电脑名.你的网络名.ts.net/`）。它和上面那条是**同一台电脑、同一条通道**，区别只在连接加不加密——不是第四条路，那条明文的照旧能用、也照旧显示。

加密之后，浏览器才肯给用系统通知、麦克风、剪贴板的完整能力。**要那三样，前提是「加密连接」，不是非得走 Tailscale**——下面第三条的公网隧道给的也是 `https://` 地址，一样够用。

两条加密路各有各的前提，说清楚免得你走错：这一条用的是形如 `你的电脑名.你的网络名.ts.net` 的域名，**它只在你的 Tailscale 网络内部解析得出**，靠的是手机客户端上的 MagicDNS。**但有些客户端没有这个能力**——HarmonyOS 上那个第三方客户端 MeshArc，它自己的说明里就写着「请用 Tailscale IP 地址」，那类手机上这条加密路走不通，不是设置没开的问题。隧道那条用的是 Cloudflare 的域名，谁都能解析，不挑手机，代价是地址每次重启都会换。

配对页上有一个开关，打开就行。第一次开需要你在 Tailscale 的后台确认一次——那是整个网络级别的开关，插件代不了你点，所以配对页会把 Tailscale 给出的那条链接直接摆在你面前，点一下就过去。要是这台电脑还没登录 Tailscale，它会说清楚，并给你登录链接。

### 三、公网访问：什么都不用装

配对页最底下有个开关，打开它，Cloudflare 会给你一个公网网址（形如 `https://随机词.trycloudflare.com/`）。手机在任何网络下都能连，**不用装任何东西**。它是**加密连接**，所以浏览器那三样（系统通知、麦克风、剪贴板）在这条路上也够用——手机上 Tailscale 的 DNS 设置开不了的话，想要加密就走这条。

两个代价，先知道再决定：

- **地址每次重启 DSH 都会换**，换了得回来重新扫一次码。
- **第一次打开会慢**——它在下载一个五十兆左右的组件，只下这一次。这期间状态那行会显示「正在打开…」，那是正常的，不是卡死。注册偶尔会失败，插件会自动重试 3 次。

打开之后**等半分钟再扫**。Cloudflare 需要一点时间把这个地址公布出去，太早扫会提示打不开——那不是坏了，是还没到时候。

## 移动端能做什么

打开链接就是全部界面：一个输入框，和最新的一条回复。

**发指令。** 打字发出去，AI 就在电脑上开始干活。

**等结论。** 跑的时候上面显示「运行中…」。这期间你可以接着发，指令会排队。任务结束，结论直接出现在页面上，同时响一声、震一下。

**两种显示模式。** 点右上角的 ⚙ 切换。「单帧」（默认）整屏只留最新一条回复，适合「我就想看这次的结果」；「聊天」是一来一回的气泡列表，适合连着追问好几轮。用一阵子你会知道自己偏哪个。

**在手机上答题。** AI 问你「选哪个」（比如让你挑一个方案）时，问题会推到手机上，点一下就算答了——**一个一个答，答错了能回头改，选项里没有的也能自己打字**。手机不在跟前（锁屏、关了页面、断了网）就自动把问题还给电脑，那边照常弹窗。

**顺手能改的三样。** 点顶栏那一行，换当前会话的模型和思考强度；切权限档位（仅可查看 / 工作区内修改 / 完全权限）；浏览电脑上的目录，登记新的工作区和会话。

**看的是结论，不是过程。** 页面上没有工具调用链、没有文件 diff。**系统层面的确认弹窗手机上点不了**（比如危险命令的审批），那类还得回电脑处理——手机上能答的是 AI 主动提给你的选择题，这两件事不一样。它的定位是一根遥控器：电视还得在那儿开着，遥控器才有用。

## 常见问题

**扫码之后打不开。**
先看手机和电脑是不是同一个 Wi-Fi。

**出门扫「公网」那条打不开。**
等半分钟再试。还不行的话，配对页上会直接显示原因。最常见的一种是**电脑上开着代理或 VPN**——Clash 这类软件的「TUN 模式」会把隧道的连接掐断，进程看着好好的，其实一条连接都没建立起来，先把它关掉再试。还有一种：这条网络就是走不通 Cloudflare（国内时好时坏，不是你哪里配错了），那就别在公网上耗着，**改用 Tailscale 那条**。

**显示「未连接」。**
手机切后台再回来经常会这样，页面会自己重连，等几秒；还不行就进设置点「重连」。

**回复到了，但没声音。**
声音要你先碰过页面才会响，点一下就行。

**手机上一直让我输密码。**
说明你打开的链接里没带密码（比如自己手打的地址）。回电脑上重新扫一次二维码就好。

**想换一个自己记得住的密码。**
在「设置 → 手机遥控」的密码那一块直接改，**至少 12 位**。改完要重启一次 DSH，重启之后手机上要重新扫一次码。

## 安全

**配对页上带着密码，别截图发出去。** 密码直接编在二维码里，扫完不用手敲——方便是方便，代价是谁拿到这张图谁就能进。

除此之外：所有接口都要密码，密码比对用定长比较；同一来源一分钟错 5 次就挡一分钟；配对信息**只允许本机读取**，同一个 Wi-Fi 下的其他设备拿不到；公网隧道默认关着，要你自己在设置页里打开；手机看不到任何文件内容——挑工作区的时候只列文件夹名字，文件一个都不列、也不读。**但有一件事要说清楚：手机上能切换 Agent 的权限档位。**切到「完全权限」，Agent 就能改这台电脑上的任何文件。这条路径是开着的。
