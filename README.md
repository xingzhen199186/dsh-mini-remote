# dsh-mini-remote

**装在手机上的 DSH 遥控器。手机上只有两样东西：你发出去的指令，和 AI 最后的结论。**

工具调用、文件读写、子 Agent 调度、思考过程——全部留在电脑上，一个字都不往手机送。

---

## 为什么会有这个东西

一轮 Agent 任务常常要跑很久。你发一条指令，它可能要想上几分钟、读几十个文件、调好几次工具，最后才给你一个结论。这中间你没法一直坐在电脑前——要出门，要接孩子，要吃饭。所以远程操控是刚需。

现有的手机端方案，大多是把桌面**完整搬**到手机上：你看到的东西和电脑上一模一样，包括每一步工具调用、每一句旁白、每一个审批弹窗。

我并不认为这种方式不好。信息完整、过程可控，如果你要在手机上认真处理一件事，它是对的。

但出门在外的时候，我需要的是另一种东西——**更轻便、更少占用注意力的交互方式**。手机屏幕就那么大，出门时的精力也就那么多。而大部分时候我真正需要的只有一件事：**这一轮跑完了，该发下一条指令了**。至于需要全神贯注去判断、去决策的交互，我不会选择在外面、对着手机做。

所以这个插件的界面做得相当「原始」：它完全省略了电脑网页端的执行步骤，只把 AI 最后的结论送到你面前。

**它的存在，是为了让你更少地去看它。**

一个用来告诉你「任务完成了」的页面，最好的状态是你瞥一眼、知道结果、发下一条，然后把手机放回兜里。它不该让你想多划两下、多看一眼、多停留一会儿。

这样你就可以更自由地支配自己的时间——而不是在陪女儿玩耍、出门游玩的时候，被困在那个小小的屏幕里。

## 安装

```powershell
dsh plugin --profile web add github:xingzhen199186/dsh-mini-remote
```

包发布到 npm 之后，直接写包名也行：

```powershell
dsh plugin --profile web add dsh-mini-remote
```

手上有源码目录的话，把目录指给它也一样：

```powershell
dsh plugin --profile web add <你放源码的目录>
```

装完**必须重启一次 DSH**，设置页里才会出现新东西。重启后左栏会多出「手机遥控」，启动日志里也会打印手机访问地址和密码。

## 配置：三条路，按需要选

三条连接方式**同时存在**，选一条就行，也可以都开着。

打开 DSH 设置（侧边栏最下面）→ 左栏「手机遥控」。这一页上每条路都有一个二维码和一条链接，二维码底下那行小字写着**什么时候用这条**，看它就够了。

### 一、内网：只在家里用

手机和电脑连同一个 Wi-Fi 时，扫「内网」那个码就能用。**不需要任何额外安装**，最省事的一条。

代价是出了门就连不上——手机一切到流量，这条就断了。

### 二、Tailscale：出门也能连，地址还固定

电脑和手机都装上 [Tailscale](https://tailscale.com)、登录同一个账号，配对页上就会自动多出这一条。地址固定，配一次以后不用再管。

代价是两边都要装一个 App。如果你不介意装，**出门在外这条最稳**。

### 三、公网访问：什么都不用装

配对页最底下有个开关，打开它，Cloudflare 会给你一个公网网址。手机在任何网络下都能连，**不用装任何东西**。

两个代价，先知道再决定：

- **地址每次重启 DSH 都会换**，换了得回来重新扫一次码。
- **第一次打开会慢**——它在下载一个五十兆左右的组件，只下这一次。这期间状态那行会显示「正在打开…」，那是正常的，不是卡死。注册偶尔会失败，插件会自动重试 3 次。

打开之后**等半分钟再扫**。Cloudflare 需要一点时间把这个地址公布出去，太早扫会提示打不开——那不是坏了，是还没到时候。

## 手机端能做什么

打开链接就是全部界面：一个输入框，和最新的一条回复。

**发指令。** 打字发出去，AI 就在电脑上开始干活。

**等结论。** 跑的时候上面显示「运行中…」。这期间你可以接着发，指令会排队。任务结束，结论直接出现在页面上，同时响一声、震一下。

**两种显示模式。** 点右上角的 ⚙ 切换。「单帧」（默认）整屏只留最新一条回复，适合「我就想看这次的结果」；「聊天」是一来一回的气泡列表，适合连着追问好几轮。用一阵子你会知道自己偏哪个。

**看的是结论，不是过程。** 页面上没有工具调用链、没有文件 diff、没有审批弹窗——**需要你点确认的操作，手机上点不了**，得回电脑上处理。它也不替你在电脑上开新会话、切模型、改配置。它的定位是一根遥控器：电视还得在那儿开着，遥控器才有用。

## 想让人不在时也收到提醒

手机锁屏或者切到别的 App 之后，浏览器里的定时器和网络连接都会被系统挂起——**这时候页面内怎么响都没用**，只能靠电脑那边发出来的推送。

改 `~/.dsh/dsh-mini-remote/settings.json`，然后重启 DSH：

```jsonc
"notify": { "enabled": true, "channel": "bark", "barkUrl": "https://api.day.app/你的key" }
```

`channel` 可以填 `bark`（iOS）、`ntfy`（跨平台，可自托管）、`telegram`。后两个各自再填 `ntfyUrl` / `ntfyTopic`、`telegramBotToken` / `telegramChatId`。

顺带说清一件事：**为什么设置里没有「网页通知」那个开关。** 手机连局域网和 Tailscale 走的都是明文 `http://`，浏览器在这种情况下连申请通知权限的接口都不给；公网那条虽然是 https，但域名每次重启都换，而通知权限是按来源授予的——等于每次都要重新授权一次。不是没做，是这条路在手机上走不通。

## 常见问题

**扫码之后打不开。**
先看手机和电脑是不是同一个 Wi-Fi。

**出门扫「公网」那条打不开。**
等半分钟再试。还不行的话，配对页上会直接显示原因。最常见的一种是**电脑上开着代理或 VPN**——Clash 这类软件的「TUN 模式」会把隧道的连接掐断，进程看着好好的，其实一条连接都没建立起来，先把它关掉再试。还有一种：这条网络就是走不通 Cloudflare（国内时好时坏，不是你哪里配错了），那就别在公网上耗着，**改用 Tailscale 那条**。

**显示「未连接」。**
手机切后台再回来经常会这样，页面会自己重连，等几秒；还不行就进设置点「重连」。

**回复到了，但没声音。**
声音要你先碰过页面才会响，点一下就行。

**手机上一直让我输密码。**
说明你打开的链接里没带密码（比如自己手打的地址）。回电脑上重新扫一次二维码就好。

**想换一个自己记得住的密码。**
在「设置 → 手机遥控」的密码那一块直接改，**至少 12 位**。改完要重启一次 DSH，重启之后手机上要重新扫一次码。

## 安全

**配对页上带着密码，别截图发出去。** 密码直接编在二维码里，扫完不用手敲——方便是方便，代价是谁拿到这张图谁就能进。

除此之外：所有接口都要密码，密码比对用定长比较；同一来源一分钟错 5 次就挡一分钟；配对信息**只允许本机读取**，同一个 Wi-Fi 下的其他设备拿不到；公网隧道默认关着，要你自己在设置页里打开；手机拿不到你的文件系统。

## 进阶

配置文件在 `~/.dsh/dsh-mini-remote/settings.json`，**首次启动后才生成**，改完需要重启 DSH。

平时用得上的就这几项：

```jsonc
{
  "port": 3090,
  "bindAddress": "auto",       // 默认自动挑出内网 + Tailscale + 本机
  "token": "",                 // 留空 = 自动生成一串随机的
  "defaultMode": "minimal"     // minimal（单帧）| chat（聊天）
}
```

`bindAddress` 一般不用动。想让手机完全连不上就填 `"127.0.0.1"`；想只在那一个地址上开门就填具体 IP，比如 `"192.168.1.5"`。

**cloudflared 从哪儿来**（按顺序找，找得到就不下载）：`settings.json` 里的 `cloudflaredPath` → 系统 `PATH` → dsh-pocket 已经下过的那份 → 自己下载到 `~/.dsh/dsh-mini-remote/bin/`。下载源依次试 GitHub 官方、`ghproxy.net`、`gh.ddlc.top`、`gh-proxy.com`。

这个插件在设计思路上参考过 [dsh-pocket](https://www.npmjs.com/package/dsh-pocket)（作者 shaobeichen）——尤其是「每条连接路径各配一条链接、一个二维码、一个密码」这种配置形态，以及公网隧道和 cloudflared 下载这两块要留意哪些坑（比如 cloudflared 的输出里会先冒出一个 `api.trycloudflare.com`，那不是给你的网址）。
