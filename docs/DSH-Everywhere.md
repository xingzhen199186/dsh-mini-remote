# DSH Everywhere 手机应用

**把 DSH 放进手机，而不是把整个桌面塞进小屏。**

DSH Everywhere 是极简遥控器（`dsh-mini-remote`）的配套 Android 应用。它不是另一套产品：连接、会话、权限和网页版共用同一套，插件仍然跑在电脑上，推理与文件也都留在电脑。

[下载最新版](https://github.com/xingzhen199186/dsh-mini-remote/releases/latest) · [返回主 README](../README.md)

---

## 它和网页版是什么关系

手机端一直有两种形态：

| 形态 | 适合 | 代价 |
| :--- | :--- | :--- |
| **浏览器网页** | 所有手机和电脑；不想安装任何东西 | 熄屏或切到别的 App 后拿不到提醒；没有系统分享；出门用 Tailscale 要另装客户端 |
| **DSH Everywhere** | Android 手机；希望锁屏也能收到审批、少开浏览器 | 需要安装 APK；屏幕操控等实验能力要额外授权 |

网页版不会消失。iOS、平板、临时借用别人的手机，继续扫码打开网页即可。

DSH Everywhere 里显示的仍然是同一套手机页面；原生层只做网页做不到的事，不另造一套聊天界面。

## 下载

安装包只从 **GitHub Releases** 发布：

- **最新版**：[github.com/xingzhen199186/dsh-mini-remote/releases/latest](https://github.com/xingzhen199186/dsh-mini-remote/releases/latest)

当前应用版本为 **0.1.0**，与插件版本分开编号。插件 `0.3.0` 起随 Release 一起提供安装包。

只提供一个安装包：

`DSH-Everywhere-0.1.0.apk`

它是**完全版**，包含全部客户端能力：配对、会话、通知与快捷审批、系统分享、内置 Tailscale，以及屏幕观察、点按、输入与截图。屏幕操作需要的无障碍权限是**可选授权**——不打开它，其他功能照常使用。

### 系统要求

- **Android 9 及以上**（API 28）；
- **arm64 手机**（当前安装包只包含 `arm64-v8a`）；
- 电脑端已经安装并启动 `dsh-mini-remote` 插件。

> **没有 iOS 应用，也没有上架应用商店。** iPhone 用浏览器网页即可。

## 安装

1. 从 Releases 下载对应的 `.apk` 到手机。
2. 点开文件。系统第一次会提示「禁止安装未知来源应用」——点「设置」，允许这个来源安装，然后返回继续。
3. 安装完成，桌面出现蓝色鲸鱼图标，名字是 **DSH Everywhere**。

> **只在可信来源下载。** 应用能连接你的电脑并接收 DSH 指令，不要安装别人转发的安装包。

### 从旧的调试签名切到正式版

正式发布包使用不同的签名。如果你之前装过开发调试包，**不能直接覆盖安装**，需要先卸载旧版再装正式版；卸载会清除旧版的配对和本地设置，装好后重新扫码。

日常从应用内更新不会触发这个问题，因为更新包与已安装版本的签名一致。

## 第一次连接

1. 电脑上打开 DSH，确认「设置 → 遥控设置」能看到地址和二维码。
2. 手机打开 DSH Everywhere，点「扫码配对」，扫描电脑屏幕上的二维码。
3. 配对成功后，App 顶栏会显示会话名或「已连接」，手机也会出现在电脑端「电脑与设备」里。

网络线路和网页版完全一致：同一 Wi-Fi 走内网；出门可以选 Tailscale、公网隧道或固定地址。具体怎么选见 [00-先选一条路](guide/00-先选一条路.md)。

> 配对链接等同于入场凭据。二维码和复制出的链接默认 5 分钟内有效，不要截图外发或投屏。

## 它比浏览器多了什么

### 锁屏与后台提醒

网页在熄屏、切到别的 App 后通常收不到提醒。App 可以在任务运行期间保持一条前台连接，把「待审批 / 被提问 / 任务完成」送到通知栏。

是否常驻由你控制：不需要时关掉「手机桥」，App 不会长期占用后台。

### 通知栏直接批准或拒绝

待审批通知带着「批准 / 拒绝」按钮，不打开 App 也能处理。已经处理过的审批再点通知，会提示「已在别处处理」，不会重复提交。

> 审批优先发到手机、超时还回电脑，这些行为与网页版共用服务端规则，不另起一套。

### 系统分享到 DSH

在别的 App 里选中文字或图片，分享给 DSH Everywhere，就能直接带进当前会话，不必复制粘贴或先存文件再上传。

### 内置 Tailscale

手机可以不装 Tailscale：App 内置一个本地 Tailscale 节点，登录账号或粘贴授权密钥后，页面请求经本地隧道进入 tailnet。

入口在 App 的「连接 → Tailscale → 内置 Tailscale（不装 App 也能连）」。登录页交给手机默认浏览器完成，不在应用内嵌登录。

### 手机桥与屏幕操作（按需开启）

「手机桥」是电脑能对手机做事的授权总开关；关着时，电脑端根本看不到这台手机。

安装包只有完全版，但屏幕操作是**单独授权**的：打开「手机桥」之后，还要在「屏幕操作」里授予无障碍服务，电脑才能读取屏幕控件、按编号点按、输入文字和截图。

「屏幕操作」里有三档确认，决定电脑每次动手前要不要先问你：

| 档位 | 行为 |
| :--- | :--- |
| **始终免确认** | 电脑操作手机时不打扰你 |
| **本任务免确认** | 只在当前任务里免确认，任务结束恢复 |
| **每次都问** | 每个动作都先在通知栏征求同意 |

> 敏感界面（设置、权限、支付、锁屏等）会被硬性拒绝或只读，避免模型自己给自己开权限。无障碍服务可以由你随时关闭，关闭后立刻失效。

### 不用装 Termux 的手机命令

App 可以借本机「无线调试」自行连自己，执行手机上的 shell 命令，不必安装 Termux，也不要求电脑的 adb 一直在线。

入口是 App 设置里的「手机执行命令（免 Termux）」：按提示在开发者选项打开「使用配对码配对设备」，把 6 位配对码填进通知即可，约 1 分钟。无线调试关着时会自动退回 Termux。

### 应用内更新

App 设置里有「App 更新 → 检查」。电脑连着时，会按你安装的构建版本取对应安装包，下载后交给系统安装；不会丢配对和设置。

更新后请回设置看一眼无障碍开关——Android 在应用更新后可能把它重置。

## 权限说明

应用只在这些功能真的要用时申请权限：

| 权限 | 用途 | 可以拒绝吗 |
| :--- | :--- | :--- |
| 通知 | 待审批、提问与完成提醒 | 可以，但锁屏提醒不可用 |
| 相机 | 扫电脑上的配对二维码 | 可以，改用手动粘贴配对链接 |
| 前台服务（数据同步） | 任务期间在后台保持提醒通道 | 可以，后台提醒会中断 |
| 安装未知应用 | 应用内更新 | 可以，改为手动从 Releases 安装 |
| 无障碍（可选） | 电脑观察与操作屏幕 | 可以，关闭后屏幕操控立即失效 |
| 无线调试（可选） | 免 Termux 执行手机命令 | 可以，改回 Termux |

**屏幕操作不是必选项。** 只发指令、收通知和处理审批时，不需要授予无障碍；打算让电脑操作手机时再打开。

## 安全边界

- **引擎在电脑**：手机不运行模型、不保存完整会话库；断网时只能看到本地已有的界面。
- **配对凭据**：长期设备凭据保存在应用私有存储里，只随请求头发送，不拼进网址。
- **电脑操控手机是额外授权**：必须同时打开「手机桥」并授予无障碍；三档确认可随时改，敏感界面有硬拒规则。
- **公网线路仍是公网**：Cloudflare、共享中继和自建中继都会让流量经过对应服务器；临时域名变化不是安全边界。
- **应用不做静默上传**：不收集、不上传使用数据；具体数据流向取决于你选择的连接线路。

更完整的通用安全说明见主 README 的[安全边界](../README.md#安全边界)。

## 排障

| 现象 | 先检查 |
| :--- | :--- |
| 扫码后一直转圈 | 电脑端 DSH 是否在运行；手机和电脑是否在同一网络；换一条线路二维码试试 |
| 电脑重启后连不上 | 回到 App 重新扫码；地址可能已经变化 |
| 能连上但收不到提醒 | 系统通知权限、电池优化、后台活动限制；国产 ROM 还需要允许自启动 |
| 通知不亮屏 | 系统设置里打开「通知亮屏提示」和锁屏通知内容 |
| 电脑点不到手机上的按钮 | 检查「手机桥」是否打开、无障碍服务是否被系统关掉；应用更新后经常需要重新打开 |
| 某些界面读不到控件 | 自绘界面读不出编号，先让电脑截图看 |
| 安装时提示签名不一致 | 之前装的是调试包或其他来源的包；卸载旧版再装正式版 |
| 更新后设置没了 | 正常覆盖更新不会清数据；若发生过卸载重装，需要重新扫码与授权 |

更完整的连接排障见 [09-连不上怎么办](guide/09-连不上怎么办.md)。
