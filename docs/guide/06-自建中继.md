# 自建中继

适合：有自己的服务器和域名，希望地址长期不变。

需要准备：

- 一台 Linux 服务器；
- 两个域名记录：一个给控制连接，一个给网页；
- 服务器上能执行安装脚本。

步骤：

1. 把插件包里的 `relay-server` 文件夹上传到服务器。
2. 在服务器上执行安装脚本，按脚本输出拿到 frp token。
3. 回到「设置 → 遥控设置 → 连接与固定地址 → 自建中继」。
4. 填控制域名、控制端口 443、传输方式 wss、公网域名、frp token。
5. 点「开启」，再点「测试连接」。

## 做完应该看到

- 两个状态灯都变绿；
- 手机用 `https://你的公网域名` 能打开。

## 注意

- 服务器 80/443 被占用时，安装脚本会退出，不会自动改已有的 Nginx；
- 需要放行 443 出站；
- 不要把 frp token 发到公开地方。
