# A/B 端协作

这一组在「设置 → 遥控设置 → A/B 端协作」，默认收起。

## 两个角色

- **作为 A 端**：这台电脑保留会话和模型，向 B 端发任务。
- **作为 B 端**：这台电脑提供文件、文件夹和命令能力，不接收 A 的会话。

A 和 B 不是两个安装包，同一台电脑可以只做一边，也可以两边都开。

## 第一次配对

A 端：

1. 打开「作为 A 端」总开关；
2. 选一条 B 能访问的地址；
3. 点「生成配对码」，得到 6 位数字，10 分钟内有效。

B 端：

1. 打开「作为 B 端」；
2. 填 A 的地址和 6 位配对码；
3. 填授权给 A 的文件夹，一行一个；第一次用专用测试目录；
4. 先不要开写入、文件夹管理和命令权限；
5. 点「配对并开启」。

## 做完应该看到

- B 端显示「已连上 A，等待任务」；
- A 端名单里那台 B 显示「在线」；
- 两边显示的授权目录一致。

## 权限

- 写入：允许 `b_write`；
- 文件夹管理：允许建目录、移动、复制、删除；
- 命令：允许执行命令和持久终端，影响范围不限于授权目录。

先只读验证，再逐项开。撤销后要重新生成配对码。

## B 端执行预设

A 端新建会话时可以选「B 端执行」预设。它会把 A 本地的 `read`、`write`、`edit`、`bash` 等文件和命令工具移除，只保留 `b_*` 操作 B 端。

- 只处理 B 端任务：优先用这个预设；
- 需要同一轮同时改 A 和 B：用普通会话，但要自己分清 `b_*` 和本地工具；
- B 项目的「新建 B 会话」会自动使用这个预设。

B 项目怎么建，见 `12-B项目.md`。
