# B 项目

B 项目把 B 端的一个真实目录登记成 A 端的工作区。A 端只保存路径映射，不复制文件。

## 前置条件

- A 端「作为 A 端」已开；
- B 端「作为 B 端」在线；
- B 端至少有一个授权目录。

## 新建

1. 打开「设置 → 遥控设置 → A/B 端协作 → B 项目」；
2. 点「新建 B 项目」；
3. 填项目名称；
4. 点「选择 B 文件夹」，从 B 的授权根开始选；
5. 需要新目录时用「＋ 新建文件夹」，这要求 B 端开了文件夹管理权限；
6. 点「新建 B 项目」。

## 做完应该看到

- B 项目列表出现项目，并显示 B 端完整路径；
- A 端工作区出现「B · 项目名」。

## 新建 B 会话

在项目那一行点「新建 B 会话」。会话从创建起使用「B 端执行」预设，本地文件和命令工具被移除，文件操作走 `b_*`。

## 浏览文件

点「浏览 B 文件」，从项目根开始；只读，不写入。写入要在 B 会话里用 `b_write`，并确保 B 端开了写权限。

## 注意

- 一个 B 目录只能登记成一个项目；
- 移除项目只删 A 端的门牌和工作区，不删 B 端真实文件；
- 项目外路径不能靠 `..` 或绝对路径绕过。
