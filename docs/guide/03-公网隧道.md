# 公网隧道

适合：出门也要用，不想装 Tailscale，只是临时用一下。

1. 打开「设置 → 遥控设置 → 连接与固定地址 → 公网访问」。
2. 打开公网访问开关。
3. 第一次会下载一个约 50 MB 的组件，等它完成。
4. 等设置页出现「公网」地址后，用手机扫码。

## 做完应该看到

- 设置页出现一条 `https://...` 的公网地址；
- 手机用流量也能打开。

## 注意

- 每次重启 DSH，这个临时地址都会变；
- 它不是固定地址，不适合长期收藏；
- 想要固定网址，用共享固定地址、专属固定地址或自建中继。

## 连不上先查

- 等 30 秒，首次域名生效需要时间；
- 看设置页有没有报错；
- 公司网络或校园网可能拦截，换手机流量再试。

## 固定地址（Cloudflare 命名隧道）

如果不想每次重启都换地址，可以用 Cloudflare 的命名隧道。需要：一个接入 Cloudflare 的域名、一个 Cloudflare 账号。

1. 打开 Cloudflare Zero Trust，进入 Networks → Tunnels → Create a tunnel，选 Cloudflared。
2. 保存后复制安装命令里的 `--token` 后面那一串，只复制 token。
3. 在隧道详情里添加 Public Hostname：
   - 子域：例如 `dsh`
   - 域名：你的域名
   - 服务：HTTP
   - URL：`http://127.0.0.1:3090`（端口以自检显示的实际端口为准）
4. 回到「设置 → 遥控设置 → 连接与固定地址 → 公网访问 → 固定地址」。
5. 公网地址填 `https://dsh.example.com`，隧道 token 粘贴进去。
6. 点「保存并开启」，状态变成「已连接」后扫码。

## 做完应该看到

- 设置页出现固定公网地址；
- DSH 重启后地址不变；
- 手机用流量能打开。

## 注意

- token 是密码，不要截图或发人；
- 404 多半是公网地址和 Public Hostname 不一致；
- 502 多半是本机端口没开或填错；
- 这条经过 Cloudflare，不是端到端加密。
