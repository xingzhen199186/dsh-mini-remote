# 自建多用户中继

适合：多个人各自使用，管理员自己搭一套 relay-multi。

## 管理员

1. 在自己的服务器上安装 `relay-multi`。
2. 打开管理后台，创建租户和邀请票。
3. 把邀请票或邀请链接发给用户。

## 普通用户

1. 打开「设置 → 遥控设置 → 连接与固定地址 → 自建多用户中继」。
2. 把邀请票粘贴进去。
3. 点「开通并连接」。
4. 等状态变成「已连接」，用固定地址扫码。

## 管理员自用

高级模式里填控制台地址和管理员密码，不需要邀请票。密码不会保存。

## 想重新试邀请票

点「清空本地配置」，确认后回到空白状态。它只清这台电脑上的身份和配置，不会删除服务器上的租户；旧租户要管理员在后台撤销。

## 注意

- 邀请票是一次性的，不要转发；
- 首次开通可能要几十秒，按钮会显示「正在连接…」；
- 看不到反馈时先留在这个页面，不要连续点。
