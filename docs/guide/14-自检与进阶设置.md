# 自检与进阶设置

## 自检

位置：「设置 → 遥控设置 → 诊断与高级 → 自检」，默认收起。

展开后能看：

- 插件版本；
- DSH 进程启动时间；
- 代码文件时间；进程比代码旧会警告；
- 手机服务端口和监听地址；
- 各条接口是否挂载；
- 最近错误。

自检只读，不包含口令或密钥。

## 进程比代码旧

看到「进程比代码旧」时，说明改过的代码还没被加载；重启 DSH 后再看。

## 进阶设置

手机页面或 PC 页面里的「进阶设置」会把本机 DSH 界面嵌进当前页。它和手机遥控共用同一个 DSH 实例，不是第二份环境。

怎么用：

1. 在手机页面或 PC 页面打开设置；
2. 找到「进阶设置」；
3. 打开后，页面内会出现完整 DSH 界面；
4. 顶部横条可以退出并返回手机页面。

这个入口默认关闭；它展示的是完整管理面，只在自己的设备上使用。

## 注意

- 自检里的报错先看最近一条，不要一次改很多地方；
- 不要为了排障反复重启 DSH。
