# 连不上怎么办

先按症状查，不要重复配对。

| 症状 | 先查 | 恢复判据 |
| --- | --- | --- |
| 手机打不开页面 | 手机和电脑是不是同一个网络；地址是不是当前那条 | 手机能打开会话列表 |
| 扫码后停在密码页 | 二维码是不是最新生成的；地址有没有过期 | 进入会话列表，电脑设备列表多一条 |
| 出门后内网地址失效 | 内网只在同一个 Wi-Fi 有效 | 换 Tailscale 或公网地址 |
| 公网地址打不开 | 首次是否还在下载/生效；设置页有没有报错 | 出现公网地址并能打开 |
| 重启后地址变了 | 是不是用了临时公网隧道 | 换固定地址，或重新扫码 |
| 手机被撤销后进不去 | 设备授权已移除 | 重新扫码配对 |
| 多用户中继一直转 | 邀请票是否过期；首次开通是否还在等 | 状态变成已连接 |

## 通用检查

1. 电脑上的 DSH 还在运行；
2. 「遥控设置」最上面有地址；
3. 设置页「自检」没有红色错误；
4. 手机和电脑的时间差不多；
5. 换一个浏览器或强制刷新再试。

不要为了排障反复重启 DSH；先把症状和设置页的报错记下来。
