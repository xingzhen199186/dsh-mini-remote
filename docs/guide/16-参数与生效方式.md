# 参数与生效方式

有些配置在设置页里改，有些要改配置文件。改完不确定是否生效时，看这一页。

| 配置 | 默认 | 怎么改 | 什么时候生效 |
| --- | --- | --- | --- |
| `port` | `3090` | 设置页/配置文件 | 重启 DSH |
| `token` | 随机生成 | 设置页「改密码」 | 重启 DSH，手机重新扫码 |
| `defaultMode` | `minimal` | 配置文件 | 即时 |
| `externalNotify` | `true` | 配置文件 | 即时 |
| `tunnel.enabled` | `false` | 设置页公网访问 | 重启 DSH |
| `tunnel.mode` | `quick` | 设置页公网访问 | 重启 DSH |
| `tunnel.publicUrl` | 空 | 设置页固定地址 | 重启 DSH |
| `tunnel.namedToken` | 空 | 设置页固定地址 | 重启 DSH |
| `tailscale.serve` | `false` | 设置页 Tailscale HTTPS | 重启 DSH |
| `feishu.enabled` | `false` | 设置页飞书 | 即时 |

## 改完怎么确认

1. 打开「设置 → 遥控设置 → 诊断与高级 → 自检」；
2. 看插件版本、进程启动时间、监听端口；
3. 如果提示「进程比代码旧」，重启 DSH；
4. 改密码后，手机要重新扫码。

## 注意

- 端口冲突时插件会自动顺延，以自检显示的「在听端口」为准；
- 配置文件里的值可能被设置页覆盖，改之前先看当前值；
- 不要为了试一个参数反复重启。
