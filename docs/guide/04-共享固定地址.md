# 共享固定地址

适合：出门也要用，要一个长期不变的网址，但不想自己维护服务器。

它由服务方提供固定入口，用户只拿邀请码和固定地址。

## 怎么开

1. 先在「公网访问 → 临时地址（快速隧道）」打开快速隧道，等它拿到公网地址。
2. 在「共享固定地址」里填服务方给的邀请码。
3. 点「保存固定中继」。
4. 等状态变成「已连接」，设置页会出现 `<id>.dsh-mini-remote.com` 这样的固定地址。
5. 用这个固定地址的二维码扫码。

## 做完应该看到

- 固定地址出现；
- 手机用这个固定地址能打开；
- DSH 重启后地址不变。

## 注意

- 共享中转会看到明文流量，不是端到端加密；
- 邀请码只用一次，不要转发；
- 没有邀请码时先找服务方，不要自己猜；
- 地址里如果带入场凭据，不要截图外发。
