# 共享固定地址

适合：出门也要用，要一个长期不变的网址，但不想自己维护服务器。

它由服务方提供固定入口，用户只拿链接或二维码。

1. 打开「设置 → 遥控设置 → 连接与固定地址 → 公网访问」。
2. 找到「共享固定地址」，按页面提示开启。
3. 如果页面给出邀请码或链接，按页面提示填入。
4. 等状态变成已连接，再扫固定地址的二维码。

## 做完应该看到

- 设置页出现一条固定的 `https://...` 地址；
- DSH 重启后地址不变。

## 注意

- 这条经过服务方的中继，流量会经过服务方；
- 没有邀请码时，先找服务方要，不要自己猜；
- 地址里如果带入场凭据，不要截图外发。
