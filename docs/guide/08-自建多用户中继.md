# 自建多用户中继

> 这一篇只讲插件侧怎么用。`relay-multi` 的安装、管理员密码、后台操作、API 和故障排查，以服务器端说明为准：
> [relay-multi/README.md](../../relay-multi/README.md)
>
> 服务器端程序在仓库的 `relay-multi/` 目录，不在插件 tgz 里。

适合：多个人各自使用，管理员自己搭一套 relay-multi。

## 管理员

先按 [relay-multi/README.md](../../relay-multi/README.md) 完成三件事：

1. 看「前提」和「安装」，在服务器上装好 `relay-multi`；
2. 打开 [管理后台](../../relay-multi/README.md#管理后台)，用 `admin` 和初始密码登录；
3. 在后台创建租户和邀请票，把邀请票或邀请链接发给用户。

首次安装只打印一次初始密码，先存好。忘记密码或想修改密码时，按 [管理员密码](../../relay-multi/README.md#管理员密码) 在服务器上执行 `set-admin`；改完不需要重启 `relay-control`，旧密码立即失效。

管理后台不要直接暴露给所有人。Basic Auth 不是多因素认证，管理员密码泄露会影响全部租户。

## 普通用户

1. 打开「设置 → 遥控设置 → 连接与固定地址 → 自建多用户中继」。
2. 把邀请票粘贴进去。
3. 点「开通并连接」。
4. 等状态变成「已连接」，用固定地址扫码。

邀请票只能成功使用一次，有效期由管理员在创建时决定，具体过期时间以服务端为准。已经使用或过期的邀请票不能再开新租户，需要联系管理员重新创建。

首次开通可能要几十秒，按钮会显示「正在连接…」。看不到反馈时先留在这个页面，不要连续点。

## 管理员自用

高级模式里填控制台地址和管理员密码，不需要邀请票。密码不会保存。

## 想重新试邀请票

点「清空本地配置」，确认后回到空白状态。它只清这台电脑上的身份和配置，不会删除服务器上的租户；旧租户要管理员在后台撤销。

## 排障

后台打不开、登录失败、改密码后仍提示旧密码、服务状态和日志，先看 [relay-multi/README.md 的故障排查](../../relay-multi/README.md#故障排查)。

插件侧连不上时，再看 [09-连不上怎么办](09-连不上怎么办.md)。
