# 先选一条路

先不要同时装几条。选一条能走通的，手机能连上之后，再考虑固定地址。

| 场景 | 用哪条 | 代价 |
| --- | --- | --- |
| 手机和电脑在同一个 Wi-Fi | 内网 | 出门就断 |
| 出门也要用，能装 Tailscale | Tailscale | 电脑和手机都要装、登录同一账号 |
| 出门也要用，不想装 App，临时用 | 公网隧道 | 每次重启 DSH 地址会变，首次要下载组件 |
| 已经在插件外配好公网入口 | 手动公网地址 | 自己维护 Tailscale Funnel 或反向代理 |
| 出门也要用，要固定网址，不想维护服务器 | 共享固定地址 | 先开快速隧道；需要服务方邀请码 |
| 服务方已单独分配固定域名 | 专属固定地址 | 需要服务方激活码 |
| 自己有服务器和域名 | 自建中继 | 要装服务器、配域名和证书 |
| 多个人各自使用 | 自建多用户中继 | 要装 relay-multi，管理员发邀请票 |
| 不想打开手机网页，只在飞书单聊收发 | 飞书 | 企业自建应用及来源白名单 |

只回答当前这一层，不要提前把后面的条件全问完。没有邀请码或激活码时，只引导用户去服务方提供的申请入口，或联系服务方；不要提供或猜测运维后台地址。
