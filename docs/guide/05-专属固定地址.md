# 专属固定地址

适合：服务方单独给你开了一个固定域名，通常会给一个一次性激活码。激活码默认 30 分钟内有效。

1. 打开「设置 → 遥控设置 → 连接与固定地址 → 专属固定地址」。
2. 把激活码填进去。
3. 点「开通并连接」。
4. 等状态变成「已连接」，再扫固定地址的二维码。

## 做完应该看到

- 设置页出现你的专属固定地址；
- 重启 DSH 后地址不变。

## 没有激活码

专属固定地址的激活码由服务方发放。可以打开[申请页](https://control.dsh-everywhere.com/request)提交邮箱获取。

这个申请入口只是为了合理分配资源、防止滥用设置的门槛。除了接收验证码所需的邮箱，不收集其他个人信息；邮箱只用于本次申请和验证，不做营销、画像或商业用途。

## 注意

- 激活码只用一次，默认 30 分钟内有效，不要发给别人；
- 没有激活码时，通过服务方提供的申请入口或联系服务方获取，不要猜后台地址；
- 停止只停这台电脑上的连接，服务器上的固定地址资源还在；
- 要彻底释放，需要服务方在后台处理。
