# Tailscale

适合：出门也要用，愿意在电脑和手机上各装一个 Tailscale。

1. 电脑和手机都安装 Tailscale。
2. 两端登录**同一个账号**。
3. 回到「设置 → 遥控设置」，看「手机连接」里有没有出现 Tailscale 地址。
4. 手机扫那条地址的二维码。

## 做完应该看到

- 手机用流量也能打开页面；
- 电脑的设备列表里出现这台手机。

## 可选：加密地址

设置页里还有「Tailscale HTTPS」。它和普通 Tailscale 是同一台电脑，只是连接加密；需要先在 Tailscale 后台开启 HTTPS。打不开时先看设置页给的那条开启链接。

## 连不上先查

- 两端是不是同一个 tailnet；
- 手机 Tailscale 是不是在线；
- 电脑上的 DSH 和手机服务是不是还在运行。
