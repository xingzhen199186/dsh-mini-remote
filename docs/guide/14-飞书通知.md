# 飞书通知

这一组在「设置 → 遥控设置 → 通知与集成 → 飞书」，默认收起。

## 飞书后台

1. 登录飞书开放平台，创建企业自建应用；
2. 在「凭证与基础信息」拿 `App ID` 和 `App Secret`；
3. 添加「机器人」能力；
4. 在「事件与回调」选择「使用长连接接收事件」，添加 `im.message.receive_v1`；
5. 开通三个权限：`im:message:receive_as_bot`、`im:message:send_as_bot`、`im:message`；
6. 创建并发布应用版本；改过能力、权限或事件都要重新发布。

## 回到插件

1. 填 `App ID`、`App Secret`，保存；
2. 打开飞书开关；
3. 在飞书单聊里给机器人发一条消息；
4. 页面或机器人会显示来源的 `open_id`（可能还有 `chat_id`）；
5. 把 `open_id` 填进「允许的 open_id」，保存后再发一次。

## 做完应该看到

- 飞书里发消息，DSH 会话能收到；
- 插件回复能回到飞书单聊。

## 注意

- 本版只处理单聊，不处理群聊；
- 白名单为空时拒绝所有来源；
- `App Secret` 保存后不回显，留空保存表示不修改；
- 不要把 `App Secret` 发到公开地方。
