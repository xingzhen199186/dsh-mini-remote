# 终端：三条路怎么分工（2026-11-12 落地）

用户的诉求：**一个 App 装完，手机上就能跑终端；想装包的人也有出路。**

于是分三层，**默认零安装，进阶按需**。

## 第一条：自研终端（默认，什么都不要装）

App 内直接调 **系统自带的 `/system/bin/sh`**（配 toybox，0BSD 许可）。

- **界面**：**2026-11-12 用户决定删掉全屏终端页，只留后台能力**（`phone_sh`，AI 用得到，人看不到入口）。曾经做过网页命令框、浮动圆钮、真 PTY 全屏页三版，都撤了；
- **执行**：`ProcessBuilder("/system/bin/sh", "-c", command)`，**不用 `Runtime.exec` 拼字符串**（那个引号解析不可靠）；
- **兜底**：默认 60 秒超时、输出上限 20 万字符，超了如实告诉你被截断；
- **不打包任何二进制、不引入任何依赖、不涉任何许可**。

**两条必须知道的边界**（代码和界面里都写了）：

1. 命令以**本 App 的身份**运行——不是 root，也不是 ADB shell，**碰不到别的 App 的私有数据**；
2. **看不到你在系统选择器里选的工作文件夹**——那是授权凭证不是路径。要那文件夹请用 `phone_fs_*` 原生文件工具。

**拖动按钮会记住位置**（免得压住网页上的控件）。**它给了什么**：敲命令、跑脚本、用系统自带的命令处理文件。

**它没给什么**：**不能 `pkg install`**。能用的是系统提供的那些命令。

## 第二条：Termux（可选增强，用户自己装）

装了就解锁**完整 Linux**：bash、apt 仓库、Python/Node/ffmpeg 随便装。

页面里已经写了三步指引：

1. 从 **F-Droid** 或 **GitHub Releases** 装（**应用商店那个已停止更新**）；
2. Termux 里执行 `echo 'allow-external-apps = true' >> ~/.termux/termux.properties`，然后**彻底关掉再打开**；
3. 回本页「手机终端」点「去授权」（那个说明弹窗点「知道了」**不会授予权限**，必须由 App 发起请求）。

**为什么它是"可选"而不是"必需"**：日常读写文件走 `phone_fs_*`，跑命令走自研终端，两头都不需要它。

## 第三条：阿尔卑斯小系统（**2026-11-12 用户已否决，不做**）

想在**不装 Termux** 的前提下还能 `apk add`，唯一像样的路是 **PRoot + Alpine**（约 **15MB**，对比 Ubuntu 那套 151MB）。

**但现在没做**，因为它有两个绕不开的代价：

1. **许可**：PRoot 是 GPLv2，Alpine 里跑 busybox 也是 GPLv2。**分发包 GPL 二进制不会传染我们的代码**（那是聚合），但**我们会成为 GPL 的分发者**——要附许可证、提供源码、遵守安装信息条款；
2. **商店政策**：Play 版**不允许运行时下载可执行文件**。

**2026-11-12 用户裁决：这条不做。** 理由就是上面两条代价——为了一小撮"既要装包又不装 Termux"的需求，把 GPL 合规和商店政策的风险背进来，不划算。界面上原本留的入口也已一并移除。

**恢复条件**（写在这里，免得以后有人重新提）：只有出现**大量用户明确要求"不装任何 App 也能装包"**，且**分发走自有渠道**、**有人负责 GPL 合规**时，才重新评估。

## 怎么选（一句话版）

| 你要什么 | 用哪条 |
|---|---|
| 敲命令、跑脚本、处理文件 | **第一条**（零安装） |
| 装 Python/Node/ffmpeg、要完整 Linux | **第二条**（装 Termux） |
| 不能装 App，又必须能装包 | **没有这条路了**——用户已否决（见第三条） |

## 许可自查清单（将来做第三条时用）

- **PRoot（GPLv2）**：分发时附源码获取方式、许可证全文；
- **Alpine rootfs（各包各自许可，含 GPL）**：保留各包版权与许可，提供源码获取方式；
- **toybox（0BSD）/ mksh（MirOS）/ xterm.js（MIT）**：保留声明与许可证文本；
- **产品名**：不得使用 "Termux" 做品牌或暗示背书。
